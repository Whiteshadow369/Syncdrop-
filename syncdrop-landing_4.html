How It Works

How Verified Attention Works

Infrastructure-grade verification. Simple enough for any earner, rigorous enough for any enterprise.

01 / 04
◈
Session Initialization
An earner joins a verified session — Zoom, Google Meet, YouTube Live, Twitch, Discord. The AVE establishes a presence baseline before any rewards are eligible.
02 / 04
◉
Proof Engine Fires
The APE deploys a time-bound verification trigger — QR Flash, Keyword Drop, Poll Gate, or Multi-Step. Only a human genuinely present can respond in time.
03 / 04
◐
Proof Object Minted
A verified proof object is created — containing confidence score, timestamp, session ID, and signal weights. VHAM is awarded proportionally. No proof, no VHAM.
04 / 04
◑
Economic Settlement
Verified VHAM settles to the earner — MTN MoMo, M-Pesa, Stripe, or PayPal. Sponsors receive cryptographic proof of attention delivered. Double-entry ledger updated.

APE Engine — Attention Proof Engine

4 ways we verify you're real

Each trigger takes under 3 seconds. Each one confirms you're genuinely watching — and updates your reward weight in real time.

⚡
Ephemeral QR Flash
An encrypted QR code appears on screen for 8 seconds. Scan it on your device for a cryptographic handshake. Location, rotation, and device integrity all verified in one step.
✅ Accuracy: 99.8% · Response window: 8 seconds
#
Live Keyword Drop
Host speaks a keyword during the event. Type it in the app within 60 seconds. Temporal accuracy means only someone actually watching in real time can catch it.
✅ Accuracy: 98.4% · Window: 60 seconds
📊
Context Poll Gate
A poll appears with a question only someone actively watching can answer. Time-bound, context-locked, tied to what's happening on screen right now.
✅ Accuracy: 97.1% · Window: 45 seconds
🔐
Multi-Step Grid Lock
Maximum confidence mode. Sequential multi-stage inputs — QR + keyword + behavior — that must all pass within seconds of each other. Used for high-value events.
✅ Accuracy: 99.9% · Window: 120 seconds
